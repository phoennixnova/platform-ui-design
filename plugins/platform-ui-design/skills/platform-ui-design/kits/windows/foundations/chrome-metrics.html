Frame shown is the Windows large breakpoint (1008 epx wide, §4.1). The title bar's trailing 138px is left empty — that region is reserved for the three system-drawn caption buttons (minimize/maximize/close); the shell owns their paint and hit-test, and a custom title bar that mis-reports it breaks Snap Layouts (§3.3). CommandBar and the NavigationView pane are from §3.4 and §3.2; PaneDisplayMode="Auto" switches LeftMinimal → LeftCompact → Left at the same 640/1008 width thresholds as the breakpoints above.
