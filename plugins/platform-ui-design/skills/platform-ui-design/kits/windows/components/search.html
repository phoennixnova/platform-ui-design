AutoSuggestBox is a TextBox with a leading query icon — 32 tall, 4px radius, --win-card background, --win-stroke-default border, matching every other text-entry control. As the user types, a suggestion list drops below: shadow-free --win-card surface, 8px radius, --win-stroke-default border, 36px rows. Choose AutoSuggestBox over ComboBox when suggestions are filtered live rather than a fixed option list.
