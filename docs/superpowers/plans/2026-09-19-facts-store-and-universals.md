# Fact Store + Data-Driven Universals — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A zero-dependency `inspect-app.mjs` that writes one read-only fact store for a reviewed app, and a `build-references.mjs` that generates `universals.md`, section indexes and the attribution table from per-platform JSON — so adding a platform or source is one data file.

**Architecture:** `references/platforms/<id>.json` is the contributor-facing data (detection globs, rule values + sources, attribution rows). `lib/rules.mjs` is the rule catalogue and the delta-lint phrase list. `build-references.mjs` generates and lints; `inspect-app.mjs` detects platforms from the same JSON and inventories the app. The rubric's Pass 0 reads the fact store; reference files keep only deltas.

**Tech Stack:** Node ≥ 18 ESM, `node:test`, `node:fs`, `node:crypto`. No dependencies. Glob matching is hand-rolled (`**`, `*`).

Spec: `docs/superpowers/specs/2026-09-19-facts-store-and-universals-design.md`

## Global Constraints

- Zero runtime dependencies; every script runs as `node <script>.mjs`.
- Tests via the glob form: `node --test "plugins/platform-ui-design/skills/platform-ui-design/scripts/test/*.test.mjs"` (62 pass today; must stay green).
- Generated files carry the first line `<!-- GENERATED by scripts/build-references.mjs — edit references/platforms/*.json instead -->` (universals.md) or are regenerated between marker pairs (`<!-- index:start -->…<!-- index:end -->`, `<!-- sources:start -->…<!-- sources:end -->`).
- Every rule id in `RULES` must exist in every platform JSON as `{value, source}` or `{na}`; the build exits 2 otherwise.
- Delta lint: a universal phrase in a per-platform reference file is a finding unless the line contains `universals.md` or is inside a code fence; `accessibility.md` Part 1 and `universals.md` are exempt.
- `inspect-app.mjs` never writes inside the app except its `--out` file; default `<root>/docs/ui-review-facts.json`.
- Subagent briefs: no browser; one plain shell command per Bash call; verify with the scripts' own `--check`/tests.

import { test } from "node:test";
import assert from "node:assert/strict";
import { RULE_GROUPS, RULES, ALL_RULE_IDS } from "../lib/rules.mjs";

test("every rule is in exactly one group and every group rule exists", () => {
  const seen = new Map();
  for (const g of RULE_GROUPS) for (const r of g.rules) { assert.ok(RULES[r], r); seen.set(r, (seen.get(r) ?? 0) + 1); }
  for (const id of Object.keys(RULES)) assert.equal(seen.get(id), 1, id);
  assert.deepEqual([...seen.keys()].sort(), [...ALL_RULE_IDS].sort());
});
test("phrases are regexes and match their canonical examples", () => {
  assert.ok(RULES["contrast.text"].phrases.some(p => p.test("must be 4.5:1")));
  assert.ok(RULES["target.min"].phrases.some(p => p.test("48×48 dp")));
  assert.ok(RULES["target.min"].phrases.some(p => p.test("44x44 pt")));
  assert.ok(!RULES["target.min"].phrases.some(p => p.test("line 44 of the file")));
});

### Task 3: `build-references.mjs` — generate universals, indexes, attribution; delta lint

**Files:** Create `SK/scripts/build-references.mjs`, `SK/scripts/lib/refgen.mjs` (pure generators), `SK/scripts/test/build-references.test.mjs`; fixtures `SK/scripts/test/fixtures/refs/` (a small `references/` tree: two platform JSONs, two delta `.md` files with index markers — one containing a planted `4.5:1` phrase and one with a pointer line — and an `ATTRIBUTION.md` with source markers).

**Produces (refgen.mjs):**
- `renderUniversals(platforms) → string` — header line, `## <group.title>` per group, table `| Rule | label… |`, rows `| <a id="…"></a>**title** | value [src] | …` where `[src]` links the URL; `na` renders as `— (<reason>)`; footer "Sources" not needed since links are inline.
- `renderIndex(md) → string` — for each `## ` heading: `- §n — <title> (line N)`; `n` is the order number.
- `applyBetween(md, startMarker, endMarker, body) → string` — replaces the marked region; if markers are absent, returns `md` unchanged and sets `applied=false` (return `{text, applied}`).
- `renderSources(platforms) → string` — table rows from every platform's `sources`, sorted by platform id then name.
- `lintDeltas(files: {name, text}[], rules) → Finding[]` — per line: skip inside ``` fences, skip lines containing `universals.md`, skip `LINT_EXEMPT` names; any `RULES[*].phrases` hit → `{file, line, rule, phrase}`.

**CLI:** `node build-references.mjs [--check] [--refs <dir>] [--attribution <file>]` — defaults `SK/references`, repo `ATTRIBUTION.md`. Exit 0 ok · 1 drift or lint findings (`--check`) · 2 platform validation errors.

### Task 4: `inspect-app.mjs` — the fact store

**Files:** Create `SK/scripts/inspect-app.mjs`, `SK/scripts/lib/inspect.mjs` (pure analyzers over an in-memory file list), `SK/scripts/lib/glob.mjs` (`globToRegExp(pattern)` supporting `**`, `*`, `?`), `SK/scripts/test/inspect-app.test.mjs`, fixture app `SK/scripts/test/fixtures/app-web-tauri/`:

```
CLAUDE.md                      "Android is a future target; Windows and iPad ship."
package.json                   deps: react, @tauri-apps/api
src-tauri/tauri.conf.json
src-tauri/gen/apple/README     (any file)
src/pages/Design.tsx           <button aria-label="Save"><svg/></button>, <button><svg/></button> (icon-only, unlabeled), <div onClick={..}>x</div>
src/ui/Ribbon.tsx              role="menu", <dialog>, className="ribbon-popover"
src/ui/tokens.css              :root { --bg: #fff; --fg: #000; }  (hex allowed here: var definitions)
src/ui/rail.css                .rail__btn { height: 38px; color: #FF3B30; font-size: 12px } @media (max-width: 820px) {}
docs/Plan and Feature List.md  "## Known issues"
docs/design/README.md          "## §5 Platform exceptions"
```

**Produces (`inspect.mjs`):** `inspectFiles({ root, files: [{path, text}], platforms }) → facts` (pure); `hashFiles(entries) → sha256`. Analyzers:
- `platforms`: for each platform JSON, `detected` = any `detect.files` glob matches a path OR any `detect.deps` in package.json deps/devDependencies; `evidence` = matched paths/deps; `surface` = `native` if any `detect.native` glob matches else `web-in-shell`; `mentions` = lines in `CLAUDE.md`/`README.md` matching `/\b<label>\b.*\b(future|later|not yet|planned)\b/i`.
- `surface`: `native` if any detected platform is native, else `web-in-shell`; `frameworks`: from deps ∩ `["react","vue","svelte","angular","@tauri-apps/api","electron","@capacitor/core","react-native","expo","next"]`.
- `inventory.pages`: files under `**/pages/**`, `**/routes/**`, `**/screens/**`, `**/views/**` with `.tsx|.jsx|.vue|.svelte`, name = basename; `components`: other `.tsx|.jsx|.vue|.svelte` files under `src/**`, each with `kinds` from tag/role/class heuristics: `button` (`<button`, `role="button"`), `textbox` (`<input`, `<textarea`, `role="textbox"`), `dialog` (`<dialog`, `role="dialog"`, `/dialog/i` in class/component name), `menu` (`role="menu"`, `/menu/i`), `popover` (`/popover|flyout/i`), `tabs` (`role="tab"`, `/tabs?\b/i`), `switch` (`role="switch"`, `type="checkbox"`), `select` (`<select`, `role="listbox"`); `controlKinds`: totals.
- `tokens`: `cssVars` = count of `--[\w-]+:` in `.css` files; `cssVarFiles`; `hexLiterals`: `#[0-9a-f]{3,8}\b` occurrences in `.css|.tsx|.jsx|.vue|.svelte` **excluding** lines that define a custom property (`--x: #…`) and excluding files whose basename contains `token` or `theme`; `fontSizeLiterals`: `font-size:\s*\d` same exclusions; `breakpoints`: unique numbers from `@media[^{]*\((?:max|min)-width:\s*(\d+)px` sorted.
- `a11y`: `clickableWithoutRole`: lines with `onClick=` on a tag that is not `button|a|input|select|textarea` and has no `role=`; `iconOnlyButtonsWithoutLabel`: `<button` whose element text up to `</button>` contains `<svg` and no letters outside tags and no `aria-label`/`aria-labelledby`/`title`; counts of `:focus-visible`, `prefers-reduced-motion`, `prefers-color-scheme`, `aria-live`.
- `targets.small`: in `.css`, rules whose selector contains `btn|button|tab|rail|chip|icon|control|toggle|switch` with `height|min-height|width|min-width:\s*(\d+)px` where n < 44 → `{file,line,selector,px}`.
- `docs`: `claudeMd`, `readme`, `knownIssues` = md files whose name or headings match `/known issues|plan and feature|todo|backlog/i`, `deviationSections` = headings matching `/exception|deviation|platform difference/i`.

**CLI:** `node inspect-app.mjs --root <dir> [--out <file>] [--force] [--platforms <dir>]`. Walks `root` skipping `node_modules|.git|dist|build|target|.claude|coverage`. Reads `.md|.json|.css|.tsx|.jsx|.ts|.js|.vue|.svelte|.plist|.xml|.kt|.swift|.xaml|.gradle|.kts` up to 512 KB each. If `--out` exists and its `hash` equals the new hash and not `--force`: print `facts unchanged (<out>)`, exit 0. Else write JSON (2-space) and print a 6-line summary (platforms, surface, pages, components, hex literals, small targets).
